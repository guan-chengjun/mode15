# 机械原理说明（教师讲义）

配合仿真平台使用的机构原理讲义，解释旋转咖啡杯（转转杯）的运动组成、
两种传动模式的工程取舍，以及仿真中每个可调参数对应的物理含义。

## 1. 整机机构组成

旋转咖啡杯是一种经典的**回转类游艺机械**，运动可拆分为两个转动自由度：

1. **公转**：主驱动电机经减速器、小齿轮与回转支承外齿圈啮合，带动旋转大转盘
   绕整机中心竖轴整周回转；全部杯位随转盘做圆周运动。
2. **自转**：每个咖啡杯绕自身竖轴旋转。自转动力的来源决定了传动模式——
   可以来自与公转耦合的摩擦轮，也可以来自每个杯位独立的驱动电机。

主要部件链路：

```text
主驱动电机 → 减速器 → 小齿轮 → 回转支承齿圈 → 旋转大转盘（公转）
                                          ├─ 摩擦轮 → 杯底盘（耦合自转）
                                          └─ 杯位独立电机 → 杯体法兰（独立自转）
中心导电滑环：固定端向旋转端供电与传输控制信号
```

## 2. 两种传动模式对比（仿真核心教学点）

### 2.1 摩擦耦合联动模式

摩擦轮通过压紧弹簧把聚氨酯轮缘压在咖啡杯底盘侧面，依靠接触面静摩擦力传递扭矩：

- 杯体自转与转盘公转**强制耦合**，自转速度随转盘转速按传动比变化，动作整齐统一
- 结构简单、成本低，只需一台主电机
- **天然过载保护**：异物卡杯时接触面打滑，避免刚性传动下的断齿与电机堵转
- 缺点：摩擦轮属易损件，受潮/沾油/磨损后会打滑丢转，转速同步精度不高

仿真对应关系：摆臂在 `±armLimit` 限位内压向杯底盘，
`杯自转目标 ω = 转盘 ω × frictionRatio(0.38)`，再经阻尼环节平滑逼近。

### 2.2 独立驱动模式

每个杯位由独立减速电机驱动，摩擦轮摆臂抬起脱开：

- 杯体之间运动完全解耦，可单独启停、调速、反转，支持互动式玩法（乘客参与控制）
- 转速控制精度高，便于实现复杂动作编排
- 成本与维护点增多：N 个杯位即 N 套电机 + 滑环供电/通信
- 失去摩擦打滑这一机械保护，需要电气限流与扭矩监控替代

仿真中切换到该模式后，摆臂会转动到脱开限位，控制台“② 咖啡杯单独控制”生效。

### 2.3 课堂对比实验建议

| 实验动作 | 观察点 |
| --- | --- |
| 联动模式运行，打开矢量箭头 | 各杯箭头大小一致、方向沿切向同步变化 |
| 切到独立模式，单杯反转 | 该杯自转角速度箭头反向，其余杯不受影响 |
| 联动模式停用单杯 | 该杯自转目标归零并缓停，公转与其他杯不变 |
| 观察摆臂角度数据 | 联动时摆臂处于压紧角，独立时停在脱开限位角 |
| 打开轨迹对比两模式 | 联动轨迹为规则摆线族；独立差速时轨迹形状分化 |

## 3. 缓启缓停的工程意义

真实电机若瞬时满速启动，转子与负载的惯性会产生冲击电流与机械冲击：

- 电气上：启动电流可达额定值数倍，触发保护跳闸、加速绝缘老化
- 机械上：齿轮/摩擦轮承受冲击载荷，螺栓松动、焊缝疲劳、乘客失去平衡

仿真用**一阶惯性环节**抽象这一过程：

```text
ω(n+1) = ω(n) + (ω目标 − ω(n)) · (1 − e^(−k·Δt))
```

`k` 即控制台中的“缓启缓停阻尼”：调小 → 启动曲线平缓、达到目标转速耗时更长；
调大 → 响应迅速、冲击更强。暂停时目标速度置零，同一公式自然实现缓停。

配合“惯性物理演示”开关：转盘上的无约束钢球在急启时因惯性打滑甩出，
缓启时则能随盘共同转动，把抽象的惯性概念变成可见现象。

## 4. 角度限位

仿真中两类限位：

- **摩擦轮摆臂限位（±0.44 rad ≈ ±25°）**：模拟机械挡块，保证压紧力不过载、
  脱开时轮缘完全离开底盘。触限后该关节角速度归零，数据面板显示 `⚠限位` 并记录日志。
- 转盘与杯体自转属于整周回转副，不设角度限位。

工程中限位通常有三级：软件限位（控制程序）→ 限位开关（电气断电）→ 机械挡块（最后防线），
仿真展示的是机械挡块这一级的运动学效果。

## 5. 回转支承与中心滑环

- **回转支承**：同时承受轴向力、径向力与倾覆力矩的大型轴承，外齿圈兼作大转盘齿轮，
  是回转类设备的标志性部件；维护重点是润滑脂与密封带。
- **中心导电滑环**：解决“固定端如何向持续旋转的部件供电/通信”的问题，
  靠碳刷与导电环滑动接触工作；碳刷磨损与环面积碳是两类典型故障。

## 6. 实时数据面板读数释义

| 读数 | 含义 | 教学用途 |
| --- | --- | --- |
| 主电机目标转速 | 变频器给定 RPM | 输入量 |
| 转盘实际转速/角速度 | 阻尼环节后的实际输出 | 对比目标值理解缓启过程 |
| 累计转角 | 转盘关节积分角度 | 验证固定步长积分 |
| 当前传动比 | 联动模式为摩擦传动比，独立模式为 1 | 模式差异量化 |
| 杯自转 RPM | 各杯自转轴实际转速 | 单杯控制与反转验证 |
| 切向线速度 | `v = ω·r` | 矢量箭头长度的数据来源 |
| 摆臂角度/限位标记 | 摩擦轮姿态与限位状态 | 理解离合动作 |

## 7. 仿真与真实设备的差异说明（避免误导学员）

1. `frictionRatio=0.38` 为教学演示取值，真实设备由轮径比、压紧力与滑差率共同决定
2. 未建模齿轮齿隙、摩擦温升、弹性变形等二阶效应，重点呈现运动学主干规律
3. 惯性物理演示为独立简化场景（钢球 + 运动学盘面），不与整机机构做碰撞耦合
4. Cannon-es 为刚体动力学，适用于惯性/碰撞演示；柔性体、流体等不在本项目范围
