# 模型制作规范

本规范是建模师与开发人员之间的接口约定。**仿真的运动绑定、射线拾取、部件树与科普弹窗
全部依赖节点命名**，请在建模与导出时严格遵守。程序化兜底模型（`src/model/ProceduralModel.js`）
即是本规范的参考实现，可对照其层级结构。

## 1. 总体要求

| 项 | 要求 |
| --- | --- |
| 格式 | 首选 `.glb`（单文件，贴图内嵌）；也可用 `.gltf + .bin + 贴图` 整组 |
| 缩放 | 任意真实尺寸均可，程序会按包围盒最大边归一化到约 6 个场景单位并自动落地 |
| 朝向 | 模型正面朝 **-Z**，高度方向为 **+Y**，转盘中心位于世界 XZ 原点附近 |
| 坐标系 | 右手坐标系（glTF 标准），Blender 导出时勾选 +Y 向上 |
| 面数 | 教学模型建议整机 ≤ 15 万三角面；单个咖啡杯 ≤ 1.2 万面 |
| 材质 | PBR（MeshStandardMaterial 兼容）：金属度/粗糙度工作流，单张材质不超过 2K |
| 动画 | **不要烘焙旋转动画**，机构运动全部由仿真引擎驱动；可保留静止的展示动画但需命名 `idle_` 前缀 |
| 压缩 | 可选 DRACO（解码器走 CDN/可本地化）；内网建议导出不压缩 GLB 减少依赖 |

## 2. 节点命名约定（强制）

识别规则（见 `src/model/PartRegistry.js`）：节点名以部件 ID **精确匹配或前缀匹配**
（`partId`、`partId_序号`、`partId_序号_子件名` 均可）；也支持在节点自定义属性
`extras.partId` 中显式指定。

### 2.1 部件 ID 表

| 部件 ID（defId） | 中文名称 | 分类 | 是否模板部件 | 数量 |
| --- | --- | --- | --- | --- |
| `base_frame` | 主机底座 | 机架部件 | 否 | 1 |
| `main_motor` | 主驱动电机 | 动力部件 | 否 | 1 |
| `slewing_bearing` | 回转支承 | 传动部件 | 否 | 1 |
| `main_turntable` | 旋转大转盘 | 执行部件 | 否 | 1（**公转旋转节点**） |
| `slip_ring` | 中心导电滑环 | 电气部件 | 否 | 1 |
| `friction_wheel` | 摩擦轮组件 | 传动部件 | **是** | 每杯位 1 |
| `cup_drive` | 杯体独立驱动单元 | 动力部件 | **是** | 每杯位 1 |
| `coffee_cup` | 咖啡杯座舱 | 执行部件 | **是** | 每杯位 1（**自转旋转节点**） |

模板部件必须带两位序号后缀，序号从 `00` 或 `0` 开始并保持连续，例如 6 个杯位：

```text
coffee_cup_0、coffee_cup_1、…、coffee_cup_5
friction_wheel_0、friction_wheel_1、…、friction_wheel_5
cup_drive_0、cup_drive_1、…、cup_drive_5
```

### 2.2 子网格命名

部件根节点下的网格以“部件 ID + 子件语义”命名，便于维护：

```text
coffee_cup_0_body          杯身
coffee_cup_0_base_disk     杯底盘（摩擦轮压紧面）
coffee_cup_0_handle        杯把
friction_wheel_0_polyurethane_wheel   聚氨酯包胶轮
friction_wheel_0_swing_arm            摆动压臂
main_motor_0_pinion_gear              输出小齿轮
slewing_bearing_0_outer_gear_ring     外齿圈
```

## 3. 层级结构（强制）

运动正确性取决于父子层级。**大转盘是所有杯位的父节点**（杯位随盘公转），
**咖啡杯根节点即自转节点**（仿真直接写其 `rotation.y`）。

```text
场景根
├─ base_frame_0                 固定不动
│   └─ base_frame_pedestal / base_frame_flange / base_frame_foot_*
├─ main_motor_0                 固定在底座；rotation.y 由仿真写入（小齿轮反转演示）
├─ slewing_bearing_0            固定齿圈
└─ main_turntable_0             ★ 公转节点：仿真写 rotation.y
    ├─ main_turntable_disk
    ├─ main_turntable_safety_rail
    ├─ slip_ring_0              装在转盘中心、随盘旋转
    ├─ friction_wheel_0         ★ 摆臂节点：仿真写 rotation.z（角度限位）
    │   ├─ friction_wheel_0_swing_arm
    │   ├─ friction_wheel_0_polyurethane_wheel
    │   └─ friction_wheel_0_pressure_spring
    ├─ cup_drive_0              杯位独立电机
    └─ coffee_cup_0             ★ 自转节点：仿真写 rotation.y
        ├─ coffee_cup_0_base_disk
        ├─ coffee_cup_0_body
        └─ coffee_cup_0_handle
    └─ …（friction_wheel_1 / cup_drive_1 / coffee_cup_1，共 N 组，均布在同一圆周）
```

### 3.1 杯位布局要求

- 各杯位到转盘中心距离（偏心距）**相等**，相邻杯位圆心角均布（6 杯位即 60°）
- 杯位自身根节点的局部坐标位于 XZ 平面、y≈0，杯体高度沿 +Y
- 摩擦轮轮缘需与对应 `coffee_cup_i_base_disk` 圆柱面**视觉接触或留 ≤2 mm 示意间隙**

### 3.2 摩擦轮摆臂朝向

- 摆臂父节点（`friction_wheel_i`）原点放在铰接轴心
- 摆臂绕**局部 Z 轴**摆动；仿真角度范围被限制在 `±armLimit`（默认 ±0.44 rad ≈ ±25°）
- 建模初始姿态取中间位（摆臂局部旋转为 0），由仿真决定压紧/脱开方向

## 4. 材质与贴图规范

1. 使用 PBR 材质，建议金属度/粗糙度工作流；避免自发光材质滥用（会污染 X 光模式观感）
2. 贴图格式：底色/baseColor 用 JPG 或 PNG，带透明（标签等）用 PNG；HDR 不放进模型
3. 贴图尺寸：整机贴图合计不超过 4K；相同材质尽量复用同一个材质球以减少 DrawCall
4. 建议按功能区分色相，与兜底模型配色思路一致：机架灰蓝、电机绿、传动件金属灰、
   摩擦轮聚氨酯橙、杯体红——方便学员在 X 光/法线模式下仍能区分部件
5. 所有网格保持可投射/接收阴影（程序默认统一开启 `castShadow/receiveShadow`）

## 5. Blender 导出操作指引

1. 应用全部变换：选中根节点 `Ctrl+A → All Transforms`，避免缩放/旋转残留
2. 清理孤立数据：`File → Clean Up → Unused Data Blocks`
3. 导出：`File → Export → glTF 2.0 (.glb/.gltf)`
   - Include：勾选 `Selected Objects`（仅导出整机集合）
   - Transform：`+Y Up` 保持勾选
   - Geometry：默认即可；需要压缩时勾选 `Compression → DRACO`
   - Material：Export Materials 勾选
4. 自定义属性（可选）：在 Blender 物体属性 → Custom Properties 中添加
   `partId = coffee_cup_0`，导出后出现在 glTF 的 `extras`，three 会解析到 `userData.partId`
5. 导出后用 [glTF Viewer](https://gltf-viewer.donmccurdy.com/) 自检：
   无报错、材质正常、节点名完整

## 6. 科普文案绑定（`public/config/parts.info.json`）

- JSON 的 key 使用 **defId**（不带序号），模板部件共享同一份文案
- 字段：`name / category / tags / principle / structure / maintenance[] / params{}`
- 更新文案**无需重新构建**，部署后刷新页面即生效
- 某个 defId 缺文案时程序不会报错，弹窗会提示“文案待补充”

## 7. 验收检查清单

建模交付前请逐项确认：

- [ ] glTF Viewer 打开无警告，材质与贴图显示正确
- [ ] 8 类部件 ID 全部能在节点名或 `extras.partId` 中找到
- [ ] 模板部件序号连续，杯位数量与 `friction_wheel`、`cup_drive` 数量一致
- [ ] 全部杯位节点是 `main_turntable_0` 的子孙节点
- [ ] `coffee_cup_i` 根节点原点位于杯体自转轴线上
- [ ] `friction_wheel_i` 原点位于铰接轴心，摆动绕局部 Z 轴
- [ ] 无烘焙旋转动画（或仅有 `idle_` 前缀动画）
- [ ] 整机面数、贴图尺寸符合上限
- [ ] 放入 `public/models/coffee_cup.glb` 后，程序日志出现
      “部件注册完成：共 X 个部件、N 个杯位”，且部件树分类完整
- [ ] 点击每个部件均可弹出对应科普信息
