# 启动文档

面向授课教师与机房运维，介绍从环境准备到成功运行的完整流程，以及常见问题排查。

## 1. 环境要求

| 项 | 要求 | 备注 |
| --- | --- | --- |
| Node.js | **>= 18 LTS**（推荐 20 LTS） | 提供内置 fetch 与 ESM 支持 |
| 浏览器 | Chrome / Edge 100+、Firefox 100+ | 需支持 WebGL2 与 ES2020 |
| 显卡 | 支持 WebGL 的集成显卡即可 | 老旧设备会自动触发性能降级 |
| 网络 | 可访问本机服务；远程模型需可访问对应 URL | 支持 CDN / 内网文件服务器 |

检查 Node 版本：

```bash
node -v
npm -v
```

## 2. 安装与启动

```bash
# 在工程根目录执行
npm install
npm run dev
```

控制台出现如下输出即启动成功，浏览器会自动打开 `http://localhost:5173/`：

```text
VITE v5.x  ready in xxx ms
➜  Local:   http://localhost:5173/
```

### 2.1 首次启动没有模型文件？

属于正常现象。程序检测到 `public/models/coffee_cup.glb` 不存在（远程地址加载失败）时，
会自动构建**程序化兜底模型**，并在日志中给出提示。兜底模型与正式模型节点命名一致，
全部教学功能（仿真、拾取、部件树、科普弹窗）均可使用。

### 2.2 放入正式模型

1. 按 [模型制作规范.md](模型制作规范.md) 制作并导出 `coffee_cup.glb`
2. 放到 `public/models/coffee_cup.glb`，刷新页面即可
3. 也可放到任意 Web 服务器/CDN，修改 `src/config/app.config.js` 的 `modelUrl`，
   或直接用 URL 参数：`http://主机:5173/?model=https://xxx/coffee_cup.glb`

## 3. 核心配置项说明（`src/config/app.config.js`）

| 配置 | 作用 | 常见调整 |
| --- | --- | --- |
| `modelUrl` | GLTF/GLB 远程地址 | 换模型、指向 CDN |
| `hdrUrl` | HDR 环境贴图地址 | 机房断网可删除该文件让其回退灯光照明 |
| `partInfoUrl` | 科普文案 JSON | 不改动代码即可更新教学文案 |
| `fallbackToProcedural` | 加载失败是否启用兜底模型 | 验收正式模型时可设为 `false` |
| `renderer.maxPixelRatio` | 像素比上限 | 4K 屏卡顿可降到 1.5 |
| `performance` | 自动降级阈值与 4 档参数 | 机房机器统一较弱时可调低 `degradeFps` |
| `cameraBookmarks` | 视角书签 | 按教室投影构图调整机位 |
| `simulation.masterRPM` | 默认主电机转速 | 控制开场演示节奏 |
| `simulation.fixedDt` | 仿真固定步长 | 一般保持 1/60，无需修改 |

## 4. 课堂常用操作路径

1. **开场总览**：默认“总览视角”，点击运行，观察大转盘缓启
2. **传动对比**：控制台切换“摩擦耦合联动 ↔ 独立驱动”，观察摩擦轮摆臂压紧/抬起
3. **内部结构**：渲染模式切到“X 光分层透视”，点击摩擦轮查看摩擦传动原理
4. **运动学**：打开“矢量箭头 + 运动轨迹”，对比两种模式下杯心轨迹
5. **限位演示**：独立模式下摆臂触及脱开限位，右侧面板出现 `⚠限位`
6. **惯性实验**：开启“惯性物理演示”，把阻尼调小（缓启）与调大（急启）对比小球打滑
7. **实验报告**：导出日志 CSV，配合右侧实时数据填写实验记录

## 5. 常见问题排查

### Q1 页面一直停在加载遮罩
- 打开浏览器控制台（F12）查看红色报错
- 若是模型 404/CORS：确认 `modelUrl` 可访问、服务器允许跨域；本项目会自动回退兜底模型
- 若是 `WebGL` 相关报错：更新显卡驱动，或在浏览器设置中开启硬件加速

### Q2 模型显示但颜色发黑/过曝
- HDR 加载失败时自动用灯光照明，可检查 `hdrUrl` 是否可访问
- 在控制台 `④ 渲染与画质` 中手动切换画质档位，确认是否关闭了环境反射

### Q3 点击部件没有弹窗
- 确认该部件节点命名符合规范（见模型制作规范），未识别的节点不会注册
- 部件被隐藏/隔离状态下不可拾取，先在左侧部件树恢复显示

### Q4 帧率很低、风扇异响
- 观察底部状态栏，自动降级会在 3 秒窗口后降档；也可手动锁定“中/低”档
- 关闭矢量箭头、轨迹、惯性物理等辅助显示

### Q5 机房无法访问公共 CDN（DRACO 解码器）
- DRACO 仅在加载压缩模型时需要。可把 draco 解码器目录整体下载到 `public/draco/`，
  并把 `app.config.js` 的 `dracoDecoderPath` 改为 `./draco/`
- 或导出**不压缩**的 GLB（见模型制作规范），则完全不需要 DRACO

### Q6 端口 5173 被占用
- Vite 会自动尝试下一个端口；也可在 `vite.config.js` 中修改 `server.port`

## 6. 离线/内网环境清单

在内网机房部署时，请确保以下资源都位于内网可达位置：

- [ ] 构建产物 `dist/`（或内网 npm 源完成 `npm install`）
- [ ] GLTF/GLB 模型文件（内网文件服务器或 dist 内目录）
- [ ] HDR 环境贴图（可选，缺失自动回退）
- [ ] DRACO 解码器（仅压缩模型需要，可本地化）
- [ ] `parts.info.json`（默认已包含在 dist/config 中）
