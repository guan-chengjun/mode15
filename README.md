# ☕ 旋转咖啡杯机械仿真科普平台

基于 **Three.js + Vite** 的模块化机械教学仿真工程。它不是简单的循环动画，而是一套带
**物理约束、传动模式切换、运动学可视化与科普知识联动**的旋转咖啡杯（转转杯）机构仿真：
学员可以观察摩擦耦合联动与独立驱动两种传动方案的差异、理解缓启缓停与角度限位的工程意义，
并通过射线拾取直接查看每个部件的原理与故障维护知识。

---

## 一、功能总览

| 模块 | 功能点 |
| --- | --- |
| 增强轨道相机 | 视角书签、自动巡检巡航、射线防穿模、阻尼轨道控制 |
| 多模式渲染 | 实体 / X 光分层透视 / 线框 / 法线视图，Outline 轮廓高亮（含遮挡边） |
| 环境与阴影 | HDR 环境贴图（PMREM/IBL）、PCFSoft 软阴影、三点布光 |
| 机械仿真 | 摩擦耦合联动 / 独立驱动双模式、角度限位、一阶阻尼缓启缓停、单步仿真 |
| 运动可视化 | 切向速度矢量箭头、自转角速度矢量、杯心复合运动轨迹 |
| 单杯控制 | 每个咖啡杯独立启停、调速（支持反转） |
| 交互拾取 | 射线拾取 + 悬浮轮廓高亮、侧边部件树（隔离/隐藏/搜索）、3D 空间标签 |
| 科普信息 | 点击部件弹出原理/结构/故障维护，文案独立 JSON 配置 |
| 数据面板 | 角速度、转速、传动比、摆臂限位角等实时数据；仿真日志 CSV 导出 |
| 工程能力 | 模块化分层、性能自动降级（4 档）、Cannon-es 惯性物理按需开关 |
| 模型策略 | GLTF/GLB **远程 URL 加载、不内嵌**；缺失时程序化兜底模型保证可用 |

## 二、技术栈

- [three.js](https://threejs.org/) `0.169` —— WebGL 渲染、GLTF 加载、轨道相机、CSS2D 标签
- [postprocessing](https://github.com/pmndrs/postprocessing) `6.36` —— Outline / SMAA / 暗角后处理
- [lil-gui](https://lilgui.com/) `0.19` —— 参数控制台
- [cannon-es](https://pmndrs.github.io/cannon-es/) `0.20` —— 可选惯性物理（动态 import 按需加载）
- [vite](https://vitejs.dev/) `5` —— 开发服务器与生产构建

## 三、快速开始

```bash
# 1. 安装依赖（Node.js >= 18）
npm install

# 2. 启动开发服务器（自动打开浏览器 http://localhost:5173）
npm run dev

# 3. 生产构建（产物在 dist/，相对路径可部署到任意子目录）
npm run build

# 4. 本地预览构建产物
npm run preview
```

> 首次启动若未放置模型，会自动使用内置程序化兜底模型，功能完整可用。
> 正式模型的制作与放置见 [`docs/模型制作规范.md`](docs/模型制作规范.md)。

## 四、工程结构

```
mode15/
├─ index.html                  # 页面骨架（画布、面板、弹窗、加载遮罩）
├─ package.json / vite.config.js
├─ public/
│  ├─ config/parts.info.json   # 部件科普文案（独立 JSON，可热替换）
│  ├─ models/                  # 远程 GLTF/GLB 模型目录（不打包进 JS）
│  └─ hdr/                     # HDR 环境贴图目录
├─ src/
│  ├─ main.js                  # 入口：加载流程与遮罩控制
│  ├─ config/app.config.js     # 全部可调参数与远程资源地址
│  ├─ core/                    # 引擎总装、事件总线、日志器
│  ├─ render/                  # 渲染器、灯光、相机、性能降级
│  ├─ model/                   # 模型加载、部件注册表、程序化兜底模型
│  ├─ simulation/              # 阻尼关节、仿真引擎、可视化、物理桥接
│  ├─ interaction/             # 射线拾取、3D 空间标签
│  ├─ ui/                      # 工具条/部件树/数据面板/日志/弹窗/gui/状态栏
│  └─ styles/main.css          # 深色工程教学主题
└─ docs/                       # 全套中文文档（见下）
```

## 六、教学操作速查

- `空格`：运行 / 暂停（观察缓启缓停曲线）
- 左侧控制台 `② 咖啡杯单独控制`：独立模式下逐杯启停、调速、反转
- `③ 教学可视化`：打开矢量箭头与轨迹，切换两种传动模式对比轨迹形状
- `④ 渲染与画质`：X 光透视查看内部摩擦轮与回转支承
- 点击任意部件：查看原理、结构与故障维护条目
- 右侧面板底部：一键导出仿真日志 CSV，用于实验报告
